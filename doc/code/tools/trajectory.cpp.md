# tools/trajectory.cpp

**概要**：`tools/trajectory.hpp` 中 `Trajectory` 构造函数的实现——把 (v0, d, h) 化为关于 `tan(pitch)` 的一元二次方程，求根后取飞行时间更短的一条弹道，输出俯仰角与飞行时间；文件内的 `g` 为源工程标定重力加速度 9.7833 m/s²。

## 全局常量

### `constexpr double tools::g`

- **作用**：真空抛体运动使用的重力加速度，取值 **9.7833 m/s²**。
- **备注**：非标准值 9.80665，是源工程按实测弹道标定出的等效重力加速度（隐含补偿了一部分空气阻力与弹速衰减），单位 m/s²。迁移时原样保留，**不要改成标准值**，否则与既有弹速标定不匹配。

## 函数

### `Trajectory::Trajectory(const double v0, const double d, const double h)`

- **作用**：弹道解算。实现要点与关键步骤（数学推导）：
  1. 真空抛体模型：水平方向 `d = v0·cosθ·t`，竖直方向 `h = v0·sinθ·t − g·t²/2`；
  2. 消去 t 并令 `T = tanθ`，整理为 `a·T² + b·T + c = 0`，其中 `a = g·d²/(2·v0²)`、`b = −d`、`c = a + h`；
  3. 判别式 `delta = b² − 4·a·c`；`delta < 0` 时置 `unsolvable = true` 并**直接 return**，不计算角度与时间；
  4. 两根 `tan_pitch_1/2 = (−b ± √delta) / (2a)`，取 `atan` 得两个俯仰角候选（高抛解与平射解）；
  5. 由水平方程反解飞行时间 `t = d / (v0·cosθ)`（`cosθ > 0`，故 t > 0）；
  6. `t_1 < t_2` 时取 `pitch_1 / t_1`，否则取 `pitch_2 / t_2` —— 即取**飞行时间更短**的低伸平射弹道；
  7. 写入成员 `unsolvable = false`、`pitch`、`fly_time`。
- **参数**：`v0` 子弹初速度大小（m/s）；`d` 目标水平距离（m）；`h` 目标相对枪口的高度差（m，上正下负）。
- **返回**：无（构造函数）。
- **备注 / 边界条件**：
  - 无解分支中 `pitch` / `fly_time` 保持成员默认值 0（源文件未初始化成员，属未定义行为，迁移时已修补，见迁移报告）；
  - `d = 0` 时 `a = 0`，`(−b ± √delta)/(2a)` 出现 0/0 → NaN，本实现不做保护；
  - `v0 = 0` 时 a 为 inf / NaN，结果不可用，同样不做保护；
  - `cos(pitch)` 不会为 0（`|θ| < π/2`），故飞行时间的计算不会除零；
  - 判别式是两个大数相减，超远距离 / 极小初速下会有有效位损失（catastrophic cancellation）。
