# tools/crc.hpp

**概要**：声明 CRC8 / CRC16 的“计算”与“校验”两组接口，用于串口报文（裁判系统、下位机、图传链路）的帧完整性检查。

- **来源**：sp_vision_25 的 `tools/crc.hpp`
- **依赖**：仅 C++17 `<cstdint>`，无第三方依赖
- **线程安全**：纯函数、无静态可写状态，可并发调用
- **约定**：所有 `len` 都是**字节数**；函数不检查缓冲区长度，越界读由调用方负责；CRC 参数（初值、位序、多项式）与源工程完全一致，改动会与下位机协议不兼容
  - CRC8：反射多项式 0x8C（0x31 的位反转），低位优先，初值 0xff，无最终异或
  - CRC16：反射多项式 0x8408（0x1021 的位反转），低位优先，初值 0xffff，无最终异或（即 CRC-16/MCRF4XX）

## 函数

### `uint8_t get_crc8(const uint8_t * data, uint16_t len)`

- **作用**：计算 `data` 前 `len` 个字节的 CRC8 值。
- **参数**：`data` —— 数据首地址（`len > 0` 时须可读 `len` 字节）；`len` —— 参与计算的字节数，**不包含** CRC8 本身。
- **返回**：CRC8 校验值；`len == 0` 时返回初值 0xff。
- **备注**：`len == 0` 合法；不校验空指针。

### `bool check_crc8(const uint8_t * data, uint16_t len)`

- **作用**：校验整帧，其中最后一个字节是 CRC8。
- **参数**：`data` 帧首地址；`len` 帧总字节数（含末尾 CRC8），**必须 ≥ 1**。
- **返回**：`true` 校验通过；`false` 数据被破坏。
- **备注**：`len == 0` 时内部 `len - 1` 会回绕为 65535 并越界读取，调用方必须保证 `len >= 1`。

### `uint16_t get_crc16(const uint8_t * data, uint32_t len)`

- **作用**：计算 `data` 前 `len` 个字节的 CRC16 值。
- **参数**：`data` —— 数据首地址；`len` —— 参与计算的字节数，**不包含** CRC16 本身（32 位长度，支持长帧）。
- **返回**：CRC16 校验值；`len == 0` 时返回初值 0xffff。
- **备注**：`len == 0` 合法；不校验空指针。

### `bool check_crc16(const uint8_t * data, uint32_t len)`

- **作用**：校验整帧，其中最后两个字节是 CRC16（小端：低字节在前、高字节在后）。
- **参数**：`data` 帧首地址；`len` 帧总字节数（含末尾 2 字节 CRC16），**必须 ≥ 2**。
- **返回**：`true` 校验通过；`false` 数据被破坏。
- **备注**：`len < 2` 时内部 `len - 2` 回绕为极大值并越界读取，调用方必须保证 `len >= 2`。
