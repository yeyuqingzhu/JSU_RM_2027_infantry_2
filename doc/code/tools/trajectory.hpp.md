# tools/trajectory.hpp

**概要**：弹道解算结果与解算入口——给定子弹初速度 v0、目标水平距离 d、目标相对枪口的竖直高度差 h，用真空抛体模型反解枪口俯仰角 `pitch`（抬头为正，rad）与弹丸飞行时间 `fly_time`（s）。

## 类

### `tools::Trajectory`（结构体）

- **职责**：一次弹道解算的结果载体。所有成员在构造函数中一次性算好，之后只读；无任何方法。
- **备注**：模型不考虑空气阻力，重力加速度为源工程标定的 9.7833 m/s²（见 `trajectory.cpp`）。

### 成员变量

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `unsolvable` | `bool` | 无解标志：`true` 表示当前 (v0, d, h) 下不存在可行抛体弹道（判别式 < 0），此时另两个成员不可用；默认按「无解」这一保守值初始化 |
| `fly_time` | `double` | 弹丸飞行时间，单位 s；取所选弹道对应的解，无解时无意义（已初始化为 0） |
| `pitch` | `double` | 枪口俯仰角，抬头为正，单位 rad；无解时无意义（已初始化为 0） |

## 函数

### `Trajectory(const double v0, const double d, const double h)`

- **作用**：解算弹道。把水平/竖直运动方程消去时间后化为关于 `tan(pitch)` 的一元二次方程，求两根（对应高低两条弹道），取飞行时间更短的一支（低伸平射弹道），写入 `pitch` 与 `fly_time`；判别式 < 0 时置 `unsolvable = true` 并立即返回。
- **参数**：
  - `v0`：子弹初速度大小，单位 m/s，必须 > 0。
  - `d`：目标水平距离，单位 m，正常使用应 > 0（d = 0 时内部会退化，见 `trajectory.cpp` 说明）。
  - `h`：目标相对枪口的竖直高度差，单位 m，目标高于枪口为正。
- **返回**：无（构造函数）；结果从 `unsolvable` / `pitch` / `fly_time` 三个成员读取。
- **备注**：
  - **调用方必须先判断 `unsolvable`**，再使用另外两个成员；
  - 无解时 `unsolvable = true`，`pitch` / `fly_time` 保持默认值 0（迁移时补上了默认成员初始化，源文件这三个成员未初始化）；
  - `pitch` 可为负（目标低于枪口时压低）；
  - 解算为纯计算、无状态、可高频调用；但 `v0` 必须与实测弹速一致，否则存在系统性偏差。
