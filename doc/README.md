## 维护规则（摘要，完整版见 `AGENT.md` §5、§6）

- **当且仅当**①修改文件导致函数作用变动、②创建或删除函数、③显式指定 时，才更新 `overview.md`、`directory_tree.md`、`code/**`。
- 更新时**只修改该文件对应的摘要与总摘要**，其余条目不动。
- 代码变更但函数作用未变 → 不更新文档。
- **例外**：`troubleshooting.md` 独立触发——**解决一个新问题就追加一条**，不受上述限制。

## 约定

- 文档正文使用中文；文件名与代码标识符使用英文/原文。
- 目录树与逐文件说明必须与仓库实际结构保持一致；新增/删除文件时同步 `directory_tree.md` 与 `code/` 下的映射。
